The problem

The Problem With Using Spreadsheets for Price Quotes

In most Microsoft-cloud deployments, opportunities live in Dynamics 365 CRM, identity is managed in Azure Active Directory, analytics run in Power BI, and data sits in Dataverse. Quoting, though, tends to live somewhere else: a spreadsheet outside all of it, which means the price the customer sees is disconnected from the systems that should own it.

01
Broken formulas, manual re-keying

Every quote starts from a copy of last quarter's Excel file. One wrong cell reference, and the margin the customer signs is not the margin finance expected.

02
Quote data outside your Azure tenant

The file lives on a laptop, a shared drive, or an email thread, instead of the Dataverse and Azure region where the rest of your business data sits.

03
Nothing to audit end-to-end

Your Azure workloads are logged and compliance-covered. Excel quotes aren't. When margin slips, there is no trail to trace back.

04
Power BI can't touch it

Every other business metric is a dashboard away. Quote data sits in files that no Power BI report can see.

05
No approval path before pricing goes out

There is no gate between an aggressive discount and the customer's inbox. By the time a manager sees the quote, it has already been sent.

Frequently asked questions

Common Questions About the CPQ Solution

Can we deploy Folio3 CPQ in our own Azure tenant?
Yes. Folio3 CPQ is designed to deploy into the customer's Azure environment, using the customer's own Azure region, network policies, and compliance controls. Folio3 handles the deployment as part of the implementation project.
What Azure and Microsoft services does the solution use?
Folio3 CPQ relies on Azure Active Directory for identity, Dataverse for storage, Power Apps for the pricing grid, and Azure Logic Apps for integration with cost sheets, ERP, and finance systems. It runs on standard Azure hosting inside your tenant.
What compliance certifications does it inherit?
The solution runs on top of Microsoft services that carry SOC 2, ISO 27001, GDPR, and other regional certifications. The app itself does not introduce a separate compliance boundary, so the underlying Azure and Dynamics 365 posture applies.
Is this a separate app, or is it built into Dynamics 365?
Built into Microsoft Dynamics 365 CRM. The CPQ Lines and Summary views appear alongside Summary, Details, and Related on the standard Quote entity, so there is no separate application to install, no second login, and no export step back to the CRM at the end.
Why does the interface look like Excel?
Sales teams already know how to build a quote in a spreadsheet, since that is typically what the current process is. The CPQ grid mirrors that interaction on purpose, so the muscle memory transfers directly and the ramp-up tends to be measured in days rather than a formal training program.
Who is the ideal customer for this?
Organizations that have chosen Microsoft Dynamics 365 as the system of record for sales, project operations, and accounting, and that want quoting to live in the same Microsoft cloud as everything else. Companies moving off Excel-based quoting are the natural fit.
Does it handle multi-currency and VAT?
Yes. Currency is set on the quote and the CPQ solution handles the local tax posture. VAT, discount, and shipping and admin fees roll into the final selling price. Multi-currency quoting is a first-class capability, not a workaround.
Can we buy the CPQ solution standalone, or does it need the CRM implementation?
It is designed to ship with a Microsoft Dynamics 365 CRM implementation, because it depends on the standard Quote entity and Dataverse being in place. Folio3 scopes the CPQ configuration alongside the CRM rollout so quoting is available on day one.
How is this different from the built-in Dynamics 365 Sales quote?
The out-of-the-box Dynamics Quote handles single-line, single-vendor quoting well. This solution adds the multi-line detail your sales team actually needs in the field, the Summary roll-up by category and business unit, and the Excel-familiar grid. Together, those are the pieces that let the CRM Quote replace the spreadsheet entirely.
Are charts and dashboards available today?
Analytics (charts, dashboards, and margin visualization over quote data) are planned as a follow-on phase, built with Power BI on top of the same Dataverse tables. The underlying data model already carries the fields the analytics work will need, so it's a delivery-order decision rather than a re-architecture.
Can we extend or customize it after go-live?
Yes. Customization is done through Power Platform. New columns, alternate approval flows, validation rules, and additional integrations are all built with the same Power Apps and Power Automate tooling your team already uses on other Microsoft applications.
